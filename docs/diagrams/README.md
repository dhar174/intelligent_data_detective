## Diagrams

### 1. `idd-agent-pipeline.mmd` — Agent Pipeline Overview
> **Hand-crafted** from `IntelligentDataDetective_beta_v5.ipynb`

A top-down view of the four execution phases:

| Phase | Agents | Responsibility |
|---|---|---|
| 1 · Ingest & Clean | `initial_analysis`, `data_cleaner` | Schema detection, missing values, outlier removal |
| 2 · Analyse | `analyst` | Statistics, correlations, pattern detection |
| 3 · Visualise | `visualization`, `viz_worker×N`, `viz_join`, `viz_evaluator` | Parallel chart generation + QA feedback loop |
| 4 · Report | `report_orchestrator`, `report_section_worker×N`, `report_join`, `report_packager` | Parallel section writing, PDF/HTML assembly |

The `Supervisor` router sits at the centre and routes between phases.
All agents share a typed `State` object (see *Shared LangGraph State* node).
`viz_evaluator` can loop back to `analyst` to regenerate analyses before finalising.

For the full node-by-node edge list, see [`../../idd_v4_state_graph.mmd`](../../idd_v4_state_graph.mmd) (auto-generated by LangGraph).

### 2. `idd-module-map.mmd` / `.dot` / `.json` — Module Import Map
> **Auto-generated** by `generate_repo_diagram.py --kind mixed --granularity module`

Covers the ten scannable Python support files (the notebook itself is excluded since it is not a `.py` file).

Edge types:
- **Solid arrow** (`-->`) — Python `import` / `from … import` dependency
- **Dashed `reads` arrow** (`-. reads .->`) — `os.getenv` / `os.environ` access to `DEBUG_MEMORY`

Key takeaways:
- `memory_enhancements` is the core dependency; all demo scripts and three test files import it.
- `test_error_handling_framework` imports `test_intelligent_data_detective` (shared fixtures).
- The only environment variable read by the support layer is `DEBUG_MEMORY` (controls verbose logging).

## Regenerating

```bash
# From repo root

# Module import + env map (mixed)
python "$env:USERPROFILE\.agents\skills\repo-architecture-visualizer\scripts\generate_repo_diagram.py" \
  --repo . --scan-root . --kind mixed --granularity module \
  --emit mermaid,dot,json --name idd-module-map \
  --output-dir docs/diagrams \
  --exclude "legacy_versions/**" --exclude "v5_analysis_reports/**"

# Env-var map only
python "$env:USERPROFILE\.agents\skills\repo-architecture-visualizer\scripts\generate_repo_diagram.py" \
  --repo . --scan-root . --kind env --granularity file \
  --emit mermaid,json --name idd-env-map \
  --output-dir docs/diagrams \
  --exclude "legacy_versions/**" --exclude "v5_analysis_reports/**"
```
